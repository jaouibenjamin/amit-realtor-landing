# דף נחיתה — עמית מהרבני נדל״ן

דף נחיתה בעברית (RTL) להצגת נכסים ולאיסוף לידים. CTA ראשי = וואטסאפ.
סטטי: HTML + CSS מקומפל (Tailwind, **self-hosted** — לא CDN).

```
.
├── index.html        ← דף הבית (hero דינמי, נכסים נבחרים, נמכרו, על עמית, טופס)
├── listings.html     ← עמוד כל הנכסים + סינון (אזור / חדרים / מחיר)
├── assets/
│   ├── styles.css    ← Tailwind מקומפל (production) — נטען במקום ה-CDN
│   ├── listings.js   ← *מקור הנתונים של הנכסים* — עורכים כאן בלבד
│   ├── logo.svg · favicon.svg · jerusalem-skyline.svg
├── robots.txt · sitemap.xml
└── README.md
```

### עדכון נכסים (listings.js) — בלי לגעת בקוד
כל הנכסים יושבים במערך `window.LISTINGS` בקובץ `assets/listings.js`. כל פריט: `area` (lehavim/ramot/beersheva), `rooms`, `price` (מספרים), `tag` (family/luxury), `img`, ו-`title`/`specs` בשלוש שפות. הכרטיסים והסינון נבנים אוטומטית מהנתונים — להוסיף/לעדכן נכס = לערוך את הקובץ הזה בלבד.

### בנייה מחדש של ה-CSS (אם משנים classes/צבעים)
ה-CSS מקומפל ל-`assets/styles.css`. לבנייה מחדש (מקומי):
```bash
npx tailwindcss@3 -i input.css -o assets/styles.css --minify
# content: index.html, listings.html, assets/*.js · התמה (צבעים/פונטים) ב-tailwind.config.js
```
(שמרו `tailwind.config.js` + `input.css` עם הגדרות התמה — ראו היסטוריית הבנייה.)

### SEO / שיתוף / אינדוקס
favicon, תגי OG/Twitter, `robots.txt`, `sitemap.xml` — מוגדרים. **כרגע `noindex` פעיל** (pre-launch). לפני עלייה לאוויר: הסירו את `<meta name="robots" content="noindex">` משני העמודים, החליפו `REPLACE-WITH-DOMAIN` ב-`sitemap.xml`/canonical, ופתחו את `robots.txt`. מומלץ להוסיף `assets/og-image.jpg` (1200×630) לתצוגה בשיתוף.

### נמכרו לאחרונה (ב-index.html, סקשן `#sold`)
3 כרטיסי הוכחה חברתית עם נתוני placeholder (`₪X,XXX,XXX`, `X שבועות`). החלף בעסקאות אמיתיות — זה מנוע האמון החזק ביותר לסוכן.

### רב-לשוני (HE / EN / FR)
מתג שפה בתפריט (HE · EN · FR). הבחירה נשמרת ב-localStorage. עברית = RTL, אנגלית/צרפתית = LTR (אוטומטי).
כל טקסט מתורגם נושא `data-i18n="key"`, והתרגומים יושבים באובייקט `I18N` בתוך ה-`<script>` שבתחתית כל עמוד.
**להוספה/עריכת טקסט:** הוסף `data-i18n="my.key"` לאלמנט, והוסף את `'my.key'` בשלושת הבלוקים (he/en/fr). חסר מפתח בשפה כלשהי → אותו אלמנט פשוט לא יתורגם.

### טופס לידים (custom — בלי Jotform)
הטופס הישן (שאלון האינטייק של Jotform) **הוסר** — הוא לא מיועד לקונים. במקומו טופס מותאם (שם, טלפון, מטרה, אזור, תקציב, הערה) ש**מרכיב הודעת וואטסאפ** מסודרת ושולח לעמית בלחיצה. אפס תלות חיצונית, בלי watermark.
**איסוף למייל/CRM — מחווט (דורש endpoint):** בעת שליחה, הטופס גם שולח את הליד ל-Formspree (אם הוגדר) וגם פותח וואטסאפ. להפעלה: צרו טופס ב-Formspree והחליפו את `FORMSPREE='https://formspree.io/f/XXXXXXXX'` ב-`index.html`. עד אז — וואטסאפ בלבד. כולל שדה honeypot (`_gotcha`) נגד ספאם.

### לוגו
`assets/logo.svg` — שחזור wordmark של "AMIT MAHRABANI" + הסלוגן `תיווך · נדל״ן · יזמות` כ-SVG וקטורי (currentColor, מתאים לרקע כהה/בהיר). מוטמע inline בהירו, בתפריט ובפוטר. **זו רקונסטרוקציה מהתמונה** — כשיש קובץ מקורי, החלף אותו.

### הירו — תמונה כהה שמטשטשת לגוף בהיר בגלילה
ה-HERO ב-`index.html` הוא תמונת רקע כהה עם הלוגו הלבן; בגלילה התמונה מיטשטשת ומתבהרת אל גוף האתר הבהיר (טקסט כהה), והתפריט עובר מלבן לכהה.
**להחלפת תמונת הרקע:** ערוך את ה-`background-image` של `#heroPhoto` (כרגע תמונת placeholder מ-Unsplash) לכתובת התמונה האמיתית של הנכס המוביל, או `url('assets/hero.jpg')` אחרי שתשים קובץ ב-`assets/`.
עוצמת הטשטוש/המעבר נשלטת ב-JS (פונקציית `onScroll`).

### עיצוב — מונוכרום (שחור/לבן/כסף) + נגיעת ירושלים
פלטה בהירה (ivory/limestone), טיפוגרפיה serif אלגנטית, הדגשות זהב דקות. ההירו ממורכז עם לוגו גדול וסלוגן.
`assets/jerusalem-skyline.svg` — צללית קו רקיע של העיר העתיקה, מוטמעת בעדינות (אטימות נמוכה) בתחתית ההירו כנגיעה מעודנת. להסרה/החלפה — ערוך את ה-SVG המוטמע בסקשן ה-HERO.

הקבצים סטטיים, אז כל אחד מהשלושה עובד ללא קונפיג מיוחד:

> דומיין: עדיין לא אושר באינטייק. כשיש דומיין — חבר אותו דרך לוח הבקרה של ההוסט שנבחר.

## מה צריך להחליף לפני עלייה לאוויר (placeholders)

כל ה-placeholders מסומנים ב-`index.html` בהערות `PLACEHOLDER` / `החלף`. עיקרי:

1. **לוגו** — באזור ה-NAV וב-FOOTER יש טקסט „עמית מהרבני נדל״ן". החלף ב-`<img src="assets/logo.svg">`.
2. **צבעים** — בלוק `tailwind.config` בראש הקובץ: `gold`, `ink`, `sand` וכו'. התאם לקודי הצבע של המיתוג.
3. **הנכס המוביל (HERO)** — תמונת הרקע, הכותרת, התיאור, והמפרט (חדרים/מ״ר/מחיר). כרגע תמונות מ-Unsplash.
4. **מדיה (דרון/וידאו)** — בסקשן `flagship` החלף את ה-`<img>` ב-`<video>` או `<iframe>` של הצילום שלך.
5. **תיק נכסים** — 3 כרטיסי `<article>` לדוגמה. שכפל/מחק כרטיסים והחלף תמונה, אזור, כותרת, מפרט, וטקסט הוואטסאפ.
6. **על אמית + המלצות** — טקסט ה-About והמספרים, ו-2–3 ההמלצות (שמות הלקוחות מסומנים `[שם]`).

### החלפת תמונות

## אנליטיקס (Google Analytics 4) — דורש הפעלה

מוטמע בשני העמודים, **חסום עד הסכמה** (באנר עוגיות he/en/fr). לא נטען כלום עד שהמבקר מאשר.

**הפעלה:** פתחו חשבון GA4 → צרו Data Stream לאתר → העתיקו את ה-Measurement ID (בפורמט `G-XXXXXXXXXX`) → החליפו את `G-XXXXXXXXXX` בתחתית `index.html` **וגם** `listings.html`. עד אז — לא נטען GA ולא נשמרות עוגיות.

**אירועים שנמדדים אוטומטית** (אחרי הסכמה): `whatsapp_click` (עם שם הנכס → "מה הכי מעניין"), `lead_submit` (עם buy/sell), `lang_switch` / `page_language` (פילוח שפה), `filter_change` (שימוש בסינון). מבקרים/תנועה — מובנה ב-GA4.

**הדשבורד של עמית:** חשבון GA4 (אפליקציה/דפדפן). אפשר לשתף גישת "Viewer" לכתובת המייל שלו.

> הערה: GA4 משתמש בעוגיות → באנר ההסכמה הכרחי, ומומלץ דף "מדיניות פרטיות" קצר (עדיין לא קיים).
